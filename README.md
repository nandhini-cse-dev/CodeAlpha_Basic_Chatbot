# CodeAlpha Basic Chatbot 🤖

A simple rule-based chatbot built using Python. The chatbot responds to predefined user inputs and provides basic conversational interaction through the console.

## 📌 Features

* Greets the user
* Responds to simple questions
* Provides a chatbot name
* Handles unknown inputs
* Runs continuously until the user types `bye`
* Simple and beginner-friendly implementation

## 💬 Supported Commands

* `hello`
* `hi`
* `how are you`
* `what can you do`
* `what is your name`
* `bye`
* `goodbye`

## 🛠️ Technologies & Concepts Used

* Python
* Functions
* `if-elif-else`
* `while` loop
* User input
* String methods

## 📂 Project Structure

```text
CodeAlpha_Basic_Chatbot
│
└── chatbot.py
```

## ▶️ How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python chatbot.py
```

4. Enter a message when prompted.
5. Type `bye` or `goodbye` to exit the chatbot.
